# monarch-s-cafe

> **The Monarch’s Mug** — Modern Indian Fine Dining & Artisanal Brews in Patia, Bhubaneswar, Odisha.

A high-performance restaurant & cafe web application built with **Astro 4**, **Tailwind CSS**, and **TypeScript**. Designed for luxury aesthetics, mobile-first responsiveness, and top-tier Core Web Vitals.

---

## 🌟 Key Features

- **Cinematic Interactive Frame Scrubber:** Mouse-wheel and touch-scrubbing through 300 16:9 WebP frames hosted on ImageKit.io CDN.
- **Responsive Mobile Layout:** Dynamic top-space headline reveal, clear video viewport, and below-frame animated stat counters (*30+ Rooftop Seats, 365 Sunset Views/Yr, 50+ Menu Items*).
- **Authentic Google Reviews Carousel:** Touch scroll-snapping carousel showcasing authentic verified Google reviews from Patia diners.
- **Curated A La Carte Menu:** Sticky category anchor navigation and dietary tags (*Veg, Non-Veg, Seafood*).
- **Interactive Gallery:** Real venue photos (Rooftop Dining, Courtyard Panorama, Artisanal Food) with instant client-side category filtering.
- **Reservation System:** Dual dispatch table reservations via Web3Forms and Cloudflare Pages Telegram alert function (`/api/telegram`).
- **CDN Edge Asset Delivery:** Zero CLS (Cumulative Layout Shift = 0) with pre-optimized WebP assets delivered via ImageKit.io.

---

## 🛠️ Tech Stack

- **Framework:** [Astro 4](https://astro.build/) (Static Site Generation)
- **Styling:** [Tailwind CSS 3](https://tailwindcss.com/) with custom design tokens
- **Language:** TypeScript (Strict mode)
- **Fonts:** Self-hosted WOFF2 (*Playfair Display* & *Inter*)
- **Deployment:** Cloudflare Pages

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Typecheck
npx tsc --noEmit

# Build production static bundle
npm run build
```
